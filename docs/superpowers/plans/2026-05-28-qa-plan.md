## QA-1: Daemon health

| # | Test | Command | Pass if |
|---|------|---------|---------|
| 1.1 | Daemon running | `sudo systemctl status ttrackd` | `active (running)` |
| 1.2 | Socket exists | `ls -la /run/ttrackd.sock` | `srwxrwxrwx ... ttrackd.sock` |
| 1.3 | Key exists + immutable | `sudo lsattr /var/lib/ttrack/.ttrack.key` | `----i--------e-- .ttrack.key` |
| 1.4 | Store dir permissions | `ls -la /var/lib/ttrack/` | `drwx------ root root` |
| 1.5 | Version correct | `ttrack --version` | `ttrack v1.0.4` (or higher) |
| 1.6 | Man page correct | `man ttrack 2>/dev/null \| head -3` | shows current version, not old |
| 1.7 | Journal clean | `sudo journalctl -u ttrackd --since '1 min ago' --no-pager` | no ERROR lines |

## QA-2: ttrack rec — basic recording

| # | Test | Command | Pass if |
|---|------|---------|---------|
| 2.1 | Non-interactive rec | `ttrack rec /bin/bash -c 'echo qa-test-$(date +%s)'` | Banner shown, session saved message, exit 0 |
| 2.2 | Quiet flag | `ttrack rec -q /bin/bash -c 'echo quiet'` | No banner, no saved message, exit 0 |
| 2.3 | Output file flag | `ttrack rec -o /tmp/qa-test.cast /bin/bash -c 'echo file-out'` | `/tmp/qa-test.cast` exists, non-zero size |
| 2.4 | Session appears in ls | `ttrack ls` | Row for session from 2.1 present, STATUS=SAVED |
| 2.5 | Central store has session | `sudo ttrack ls-user $USER` | Same session visible, TYPE=cmd |
| 2.6 | Cast file encrypted | `sudo strings /var/lib/ttrack/$USER/$(sudo ttrack ls-user $USER \| tail -1 \| awk '{print $3}') \| head -2` | First line `TTEC1`, rest ciphertext |
| 2.7 | Local file plaintext | `head -1 /tmp/qa-test.cast` | Valid JSON `{"version":2,...}` |
